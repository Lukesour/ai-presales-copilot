# 数据与模型实验规范

- 每个数据集、prompt、模型、adapter、知识快照和结果报告都记录来源、版本、hash、许可和采集日期；
- JSONL 数据集用同目录 manifest 记录文件 hash、来源路径、版本、许可、敏感级别和用途，并由只读检查脚本校验；
- 不提交真实客户数据、凭据和未脱敏的私有 trace；
- 合成数据必须标记 `synthetic`，除非存在人工核验记录，否则不能称为 expert gold；
- 仅用于检索的证据不得静默变成训练数据；
- 微调输入和输出 schema 必须版本化，并在生成前校验；
- train/dev/test 按来源案例分组，防止同一案例泄漏到多个 split；
- 模型生成记录只有经过确定性安全、schema 和证据检查后，才能进入 `filtered_synthetic`；
- 没有匹配的外部证据时，不得把模型结果描述为生产准确率、SLA、容量或合规证据；
- 评测报告保留失败请求和截断信息，禁止删除失败样本以美化指标；
- 模型不可用或结构化输出非法必须在报告和运行状态中可见。
