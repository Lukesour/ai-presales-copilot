# GOV-001 — 治理基线

Status: Completed  
Owner: Repository maintainer  
Risk: Boundary  
Completed: 2026-09-11

## 目标

建立 Bilu 风格的单仓权威来源体系，覆盖架构、能力、任务、memory、命名、注释、测试、
契约和安全边界。

## 非目标

- 不执行生产部署或外部系统写入。
- 不进行无关功能重写。
- 不在本任务中立即拆分所有既有超长文件。

## 范围

根级 `AGENTS.md`、项目索引、工程规范、功能/任务模板、治理检查、Makefile 和 CI 入口。

## 兼容策略

治理元数据只描述责任和验证，不授予部署、外部写入或真实客户数据处理权限。保留用户已有
工作树改动，不执行 reset 或无关回滚。

## 验收

- 权威来源文件存在，且相互链接不重复定义状态事实。
- memory 只有规定的三个活动章节。
- 功能/任务 ID 和状态值唯一且有效。
- 治理检查可以通过，且不依赖重写业务文件。
- 用户已有改动保持不变。

## 验证

```bash
make governance
make file-length
git diff --check
```

## 阻塞项

本任务无阻塞。既有超长源文件由独立的 `FILE-RATCHET-001` 跟进，首轮仍为 report-only。
